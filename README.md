# Beaver

**Beaver** is a Git-native task log for software projects.

It stores tasks/issues as Markdown files inside your repo so humans and coding agents can coordinate work through Git.

## Why Beaver?

Most task trackers live outside the codebase. Beaver keeps project work close to the code:

- Markdown-first
- CLI-driven
- Git-friendly
- Local by default
- Human-readable
- Agent-friendly
