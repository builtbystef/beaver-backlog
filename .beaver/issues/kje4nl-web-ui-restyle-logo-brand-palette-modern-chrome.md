The web UI predates the brand: purple accent, flat gray panels, text-only nav. Bring in the beaver logo and restyle around it.

- Embed the logo (nav, 36px) and a favicon, cut from the supplied artwork.
- Recolour both themes from the logo: burnt orange accent (#e26628 dark / #c2521a light), navy panels in dark, cream surfaces in light.
- Modernise the chrome: sticky three-zone topbar (brand left, nav pills centred, search right), shadows and hover lifts on cards, rounded table panel, accent-filled primary buttons (first state move, create/save/note/repair), soft focus rings.
- Centre the write forms and issue detail as one prose-width column via main:has().
